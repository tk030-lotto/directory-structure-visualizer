# Directory Structure Visualizer

---

## 概要・目的

ディレクトリ構造を解析し、ツリー形式で可視化・AIプロンプト等へ貼り付け可能なMarkdownテキストを生成・出力するツールです。

---

## 主な機能・特徴

- フォルダ選択 / ドラッグ＆ドロップによるディレクトリ読み込み
- 隠しファイル・`node_modules` 等のカスタム除外フィルタリング
- インタラクティブなグラフィカルツリー表示（フォルダーの展開・折りたたみ）
- Unicode (`├──`, `└──`) および ASCII 形式のMarkdownツリー生成
- クリップボードへのワンクリックコピー ＆ `.md` ファイル保存
- ダークテーマを採用したツリー表示UI

---

## 使用方法・インストール手順

1. リポジトリをクローンまたはダウンロードします。
2. プロジェクト直下の **`ツール起動.bat`** をダブルクリックしてください。  
   自動的に依存パッケージのインストールとローカルサーバーの起動が行われ、既定のWebブラウザでツールが開きます。
